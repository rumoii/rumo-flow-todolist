# Rumo-Flow 稳定化与模块化规格

状态：2026-09-07 批准实施的稳定化规格。原实施阶段不含发布；后续单独批准提交推送并发布 v0.7.0-rc.1，发布范围见 RC 发布说明。个人数据库操作仍不在授权范围内。

## 目标

- 保留单机、离线优先定位及现有视觉风格，分阶段整理前后端职责。
- 所有全局新建入口打开快捷捕获窗，不改变主窗口页面；任务写入后同步相关窗口。
- 任务详情、每日复盘、视频编辑和快捷捕获输入自动保留独立草稿，跨重启恢复，手动保存才修改正式数据。
- 草稿防止乱序覆盖、保存后复活和导入时旧窗口回写；正式保存和草稿清理共享事务。
- 新增数据库迁移 8；备份 v4 包含草稿并继续支持原有旧格式。
- 拆分任务、组织信息、心流、设置、草稿和备份职责，不保留重复写入实现。

## 必须保持

- 任务、清单、重复规则、标签、筛选、提醒、撤销、主题及历史数据语义保持兼容。
- 不将未保存草稿计入正式任务变化或已完成复盘。
- 保存失败保留输入；备份恢复失败不改变正式数据与草稿。
- 删除的对象不能通过旧草稿重新创建；后台刷新不覆盖编辑内容。
- 不接触个人用户目录数据库；提交、推送与预发布按后续批准的发布方案执行。

## 失败模型

风险级别：Tier 3，涉及持久化、事务、窗口生命周期与迁移。

验证写入失败、修订号冲突、过期请求、实体删除、导入期间编辑、正常退出和强制终止。
仅成功落盘的草稿保证可恢复；断电和强制结束不保证最后未确认的输入。
所有数据库测试使用任务创建的临时目录；桌面验收使用独立 userData，不修改用户安装实例。

## 实施与证据

使用现有 Vue、TypeScript、SQLite、Vitest 和 Playwright，不新增生产依赖、不创建分支。
新增源码、回归测试、本规格及验证报告；生成物放入忽略的 test-results、out 或 release。
顺序：回归用例、新建与同步、后端分域与草稿备份、前端分域与草稿接入、完整回归与桌面验证。
验证命令：Node 24 下的 pnpm typecheck、pnpm test、pnpm test:e2e、pnpm build，以及隔离 Electron 用例。
浏览器模拟接口证据与真实 Electron/SQLite 证据分别记录；未运行的安装升级场景保持待验收。
