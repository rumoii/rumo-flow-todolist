# 任务与心流编辑体验规格

状态：源码实现与本地验证完成，未发布或安装。结果见 [验证记录](EVIDENCE-editor-experience.md)。规格依据已批准的任务与心流体验方案。风险等级 Tier 3（持久化、并发、迁移）。

## 范围与设置

沿用当前工作区和既有工具，不新增依赖、分支或外部服务。保留已有窄屏修改。不提交、推送、发布、安装或操作日常数据库。测试使用临时 SQLite 和独立 localhost 浏览器。

## 行为与不可违反项

- 任务详情采用文档式单页，顺序为标题、安排与重要程度、清单标签、子任务、备注、重复来源；默认约 600px，展开只占右侧内容区。
- 计划表示何时做，截止表示最晚何时完成，提醒必须具备截止日期和时间。已设信息始终有摘要。
- 任务详情文本 700ms 自动保存，失焦提交，离散操作立即提交。保存期间接受新输入，旧响应不得覆盖它。无效输入只保留草稿；恢复旧草稿需明确应用。
- 视频、复盘与新建输入手动提交。离开只处理受影响上下文，提供保存并继续、保留草稿并继续、取消；部分成功只重试剩余项。
- 列表新建、子任务、视频链接草稿可靠落盘，分别保留原创建上下文、父任务和日期。创建记录和消费草稿同事务，重试不得重复创建。
- 正常退出与更新等待编辑检查；强制终止只保证恢复已落盘内容。失败不得宣称保存成功。
- 心流保留输入、复盘、历史和日历。宽内容区（960px）日历默认可见，手动选择在会话中优先。历史返回保持位置；三问六问切换不清空，只有明确保存才计为已复盘。
- 备份导入导出仅 v6，拒绝旧格式发生在数据替换前。有效现有数据库受控升级，升级前一致性快照，失败回滚；恢复旧快照须使用原应用版本。
- 编辑控制器、导航协调、草稿持久化各自唯一负责其状态；不复制缓存或引入兼容旧错误实现的分支。

## 失败模型与验证

| 风险 | 可证伪验证 |
| --- | --- |
| 保存中输入被丢弃或旧响应覆盖 | 可控 Promise 延迟、连续更新、失败重试单元测试 |
| 切换、退出、恢复导致丢失 | 导航三种结果、落盘失败、代际变化、隔离 Electron 重启 |
| 创建重试产生重复或关联漂移 | SQLite 事务回滚、旧 revision、原始日期和父任务断言 |
| 无效备份损坏现有数据 | v6 往返、v5 拒绝、导入失败前后数据与代际比较 |
| UI 改动损坏有效操作 | 计划、重点、置顶、重复、批量、回收站、心流针对性回归 |
| 操作不可发现或窄屏溢出 | 三种视口、两主题两密度、键盘、截图、控制台与网络检查 |

复用 typecheck、Vitest、build、Playwright 和隔离 Electron。未配置变异工具，以故障注入和拒绝路径替代，不声称变异覆盖率。源码与模拟接口验证不代表安装验收。
