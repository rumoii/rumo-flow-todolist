## 场景与证据

- `updates.test.ts`：正式渠道、关闭自动下载/退出安装、RC 到正式版和不降级、启动检查开关、并发检查、下载取消与迟到结果、校验错误、草稿失败阻止安装、安装器错误及通知失败不污染成功状态。版本比较调用真实 NsisUpdater；网络和安装动作使用受控替身。
- `window-barrier.test.ts`：必须收齐各窗口确认；拒绝和超时恢复窗口；安装成功准备后持续保持锁，取消释放；错误发送不能阻止其他窗口恢复。
- `arrangement-repository.test.ts`、`planning-repository.test.ts`：真实 SQLite 下保持提醒标记与同日重点；版本、代次和任一草稿冲突整批拒绝；强制第二项 SQL 失败时回滚；回收站、重复任务与 v5 设置往返不变。
- `draft-coordinator.test.ts`、`ipc.test.ts`：单项和批量采用同一数组同步协议；每个干净缓存都同步，有未提交输入的任务不会覆盖；批量事务后发送完整快照。
- `batch-selection.test.ts`：可见候选去重、范围变化清理、500 项上限、保持选中时的版本、服务端失败保留选择、写入成功后刷新失败不重复提交。
- `updates-batch.spec.ts`：浏览器验证浅色/深色及最小窗口设置、开关、显式下载、关闭设置继续下载、失败提示、今天展开/折叠提醒、周卡片及过滤后清空；同名桌面用例验证实际版本、剪贴板无任务内容、批量草稿冲突和计划写入。
