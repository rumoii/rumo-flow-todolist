# 快捷安排与今天执行规格

状态：依据已批准的 A 批方案实施；2026-09-08。基线 `9e58a5d`。不包含 B/C/D 批、提交、推送、安装或发布。

## 行为

- 顶层未完成任务可快捷安排今天、明天、本周、本月、未安排，也可指定日/周/月计划；相对日期由主进程在提交时按本地日历计算。
- 今日重点可独立取消；设为重点同时安排到今天。普通置顶不受影响。同计划保持重点，跨日/改变精度/未安排清除失效重点。
- 今天依次显示重点、其他任务、折叠的今日到期及过往未完成提醒；搜索/标签筛选统一生效，提醒保留原去重规则。
- 计划写入只触及计划、重点和单调修改时间。禁止改变截止日期、提醒及已通知标记、排序、重复规则、清单、标签或任务身份。
- 同任务有未保存详情草稿时拒绝快捷写入并提供打开详情入口；不自动提交或丢弃草稿。正式详情提交不受这个新命令的拒绝规则影响。
- 复用窗口屏障，在事务检查前暂停并落盘所有窗口的输入；失败必定恢复交互。成功时同步目标任务的干净编辑器缓存后恢复编辑。
- 旧任务版本、旧数据代际、已完成/已删除/子任务、非法参数均拒绝。相同目标不写入、不重复广播。
- 周拖放与新安排入口共用命令；批量操作不改。捕获及当前页添加说明实际去向，默认计划及自动关闭规则不变。
- 快速捕获右上角提供关闭按钮，与 Esc 共用保留草稿后关闭的入口；保留失败不关闭，提交及关闭期间防止重复操作。

## 接口与风险

新增 `tasks.arrange`，输入任务编号、所见修改时间、数据代际、计划或重点操作，输出 Task。扩展 lifecycle 原因及成功恢复时的任务快照；主进程、preload、renderer 同版本交付，无兼容层或数据库迁移。

失败模型：跨窗口尚未落盘输入被覆盖；屏障超时卡死；恢复备份后的旧请求写入；旧编辑器缓存复活计划；提醒重复发送；成功后刷新或通知错误导致误报写入失败。

## 验证

先以针对性测试覆盖失败模型，再验证 SQLite 命令、IPC、窗口屏障、草稿协调器、界面及真实 Electron。复用仓库类型检查、单元测试、浏览器和桌面测试工具，不新增依赖或全局门禁。浏览器使用独立 localhost 模拟接口，桌面仅使用临时 userData；两层证据分开记录。独立变异工具未配置，使用拒绝路径、只写指定字段断言和故障注入代替，不声称具备变异覆盖率。
