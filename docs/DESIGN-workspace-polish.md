# 统一搜索与单页任务详情

## 交互与边界

- 搜索是工具，不是业务页面。侧栏顶部和 Ctrl+K 打开同一个浮层；全部内容搜索正式任务、视频及复盘，排除草稿和回收站。结果沿用现有导航和草稿保护。
- 当前列表关键词在浮层内编辑，显式应用后才改变原列表；取消不应用。页面关键词标签支持重开和清除。全局查询不覆盖列表筛选；切换任务页面清除临时关键词，心流历史编辑返回保留筛选。
- 心流每日编辑、标签管理和回收站不提供当前列表搜索；心流历史仍提供日期、状态、分页及只读展开，不被全局结果页替代。
- 详情默认 600px，并受列表区域宽度约束；展开铺满列表区域，保留侧栏可见但不可误操作，不改变系统窗口状态。两种尺寸共用同一编辑实例，关闭后恢复默认宽度。
- 单页依次展示标题、安排与重要程度、清单标签、子任务、备注、重复及可用来源。计划明确表述为“什么时候做”，截止表示最晚完成时间，提醒依附截止日期和时间。底部固定显示自动保存状态及可重试错误。
- 详情重点使用星标，与重要程度分开。有效属性自动保存，恢复的旧任务草稿需明确应用；子任务和心流保持手动提交。展开和收起不额外提交草稿。
- 任务行和周卡片共用四项菜单：查看详情、置顶、重要程度、删除。重要程度在同一浮层切换选项；删除使用原确认、回收站和撤销。菜单通过 Teleport 脱离任务行的 transform 与裁切容器，键盘关闭恢复触发按钮焦点。
- 搜索、详情、菜单和子任务过渡复用动效变量，支持系统减少动态效果。表单与文本不做缩放动画。

## 职责

搜索交互状态由工作区持有；任务过滤逻辑不变，心流关键词通过 model 传入历史模块，历史组件不依赖整个任务工作区。全局搜索沿用 tasks.search，历史仍调用 flow.history。任务编辑控制器、时间标签子任务组件、心流表单及日历分别承担自身职责；共享离开检查与持久化草稿协调器。编辑体验改动涉及 schema 10、备份 v6 和条件覆盖提交，见 [编辑规格](SPEC-editor-experience.md)。

不保留旧历史搜索页面、导航分支和重复输入框，不建立通用插件或命令框架。回收站原先借用历史搜索行样式，拆成自己的行样式以保留有效展示。

## 验证

- 搜索组件测试覆盖取消、应用、不同范围隔离、历史关键词保留、过期响应、失败重试、关闭后请求失效与草稿失败阻止跳转。
- 浏览器测试覆盖筛选与批量选择、四项菜单及二级返回、菜单离开裁切容器、详情展开与收起、小窗口横排添加按钮、保存失败保留输入。模拟接口不证明 SQLite 保存。
- Electron 测试使用临时 userData，验证实际保存、星标、全局搜索定位、删除与撤销，并回归历史补录、跨窗口草稿、安排及偏好。
- Playwright MCP 使用 localhost 独立浏览器检查浅色 1240×780、深色紧凑 900×600、详情展开、关键词应用和菜单。截图位于忽略目录 test-results；不使用日常数据库。

### 窄窗口布局修正

- 周看板每列至少 180px，空间不足时只在看板内横向滚动；标题、侧栏及本周待细化区域不跟随横移。卡片首行放完成、标题和菜单，计划与重点放在下方，批量选择保留独立位置。
- 日期控件分开布局图标、日期和箭头，不逐字换行；极窄容器仅省略日期文字，悬停及无障碍名称保留完整日期。非可编辑任务的计划文字采用相同规则。
- 任务行、详情和批量操作中的长标签及清单名限制宽度并保留完整提示，短操作控件整项换行，不对正文全局禁用换行。
- 计划选择器位于 label 内时，选项点击阻止标签默认激活，避免选择后重新打开下拉菜单并遮住操作按钮。
- 窄窗口回归覆盖 900×600、1240×780、1600×900、深浅主题及两种密度，并检查最右列滚动、拖拽、菜单、焦点返回、批量操作和长元数据。
- 修正后类型检查、构建通过；158 项单元测试、44 项浏览器测试和 8 项隔离 Electron 测试通过。Playwright MCP 在 localhost 模拟接口检查页面及菜单，未观察到控制台错误或失败请求。
- 此次修正未生成安装包、覆盖安装、提交或发布；现有 rc.3 安装版不包含这些未提交修改。
