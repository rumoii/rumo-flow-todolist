# 设置与桌面外观验证记录

日期：2026-09-07。基线为 `15d3766`，验证对象是该提交之上的工作区修改，不是已发布的 RC 安装包。

## 保存失败的原因

在临时 `--user-data-dir` 启动真实 Electron，操作设置中的主题切换，复现“偏好保存失败”。通过 CDP 捕获已处理异常，得到 `Error: #<Object> could not be cloned` 与 `Error: An object could not be cloned`，调用位置为 `saveSettings`。同一窗口直接提交普通对象 `{ theme: 'dark' }` 成功。

原实现将 Vue 响应式设置对象直接传入桌面桥接，异常在数据库写入前发生。修复改为按字段提交普通对象，保留服务端校验；主题、密度、视频额度与复盘提醒分别保存。保存中阻止重复提交，失败恢复原值并显示具体操作；持久化后的通知失败不再伪装成数据库写入失败。

## 功能与数据边界

- 标签管理独立为侧栏业务页面；创建、改名、颜色与删除复用原接口。后台刷新保留未保存的标签编辑，恢复备份时清空旧编辑。删除保留任务并清理引用。
- 视频额度位于心流输入记录，仅今天可修改；范围仍为 0～10 整数，影响今天及后续日期，历史日期不变。仅修改主题不会重写当天的额度与更新时间。
- 复盘提醒位于每日复盘，与正文分别保存；设置更新不覆盖正在编辑的复盘草稿。
- 设置分为外观、快捷键、数据与备份。主题卡片、内容密度、错误提示及小窗口焦点行为纳入回归。
- Windows 主窗口采用主题化背景与原生窗口按钮，保留既有关闭前草稿屏障和关闭到托盘行为。快速捕获窗口仍使用原来的窗口形式。
- SQLite 结构、配置键及备份 v4 格式未变，不增加迁移。所有数据库测试使用临时目录，没有打开或改写日常用户数据库。

## 浏览器与桌面证据

专用 Playwright MCP 标签页使用 `127.0.0.1:5187`，仅加载工作区前端和内存 API fixture。检查 1240×780、900×600，浅深主题、设置分类、标签创建与改名、删除确认焦点、额度与提醒交互。浏览器 fixture 不提供原生窗口按钮，也不能证明 SQLite 保存。

小窗口视觉检查发现侧栏溢出后，浏览器自动聚焦会滚动整个 `overflow:hidden` 工作区，使正文被顶栏遮挡。修改为侧栏独立滚动后，工作区 `scrollTop=0`、正文顶部为 36px，900px 宽度没有横向溢出。默认尺寸设置内容无需滚动，小窗口仅内容区滚动，关闭按钮和分类导航固定。

真实 Electron 测试从构建产物启动：验证主题及密度写入、快速捕获同步、重启恢复、额度刷新、提醒修改时保留正文草稿，以及注入写入错误后的回滚。窗口最大化、还原、最小化与关闭到托盘通过 BrowserWindow API 测试；原生按钮实际点击、拖动和 Windows 贴靠尚未人工验收。
