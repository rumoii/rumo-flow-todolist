## 针对性行为

- SQLite 对比任务所有原始列，确认安排只改计划、重点及修改时间，保留 `reminder_notified_at`、截止、提醒、重复规则及排序；同目标返回原版本。
- 固定时钟覆盖午夜跨年、明天、本周、本月及自定义周规范化；非法目标、旧版本、旧代际、已完成、删除与子任务被拒绝。
- 草稿冲突拒绝不改变正式任务或草稿；其他任务草稿不阻塞安排，正式详情提交仍可使用。
- 窗口确认覆盖全窗口 ACK、非目标窗口伪 ACK、超时、落盘失败、重叠操作、恢复通知异常；失败不执行业务写入，其他窗口仍恢复。
- 协调器覆盖干净缓存同步、未落盘 / 已保留草稿保护，以及迟到编辑器读取不能复活旧计划；恢复备份作废安排面板及在途代际读取。
- 界面覆盖重点与普通置顶分离、提醒折叠与搜索 / 标签筛选、安排失败留在面板、重试及详情入口、任务移出后的焦点恢复、周拖放与周卡片、自定义周计划。
- 真实双窗口覆盖未提交捕获输入的保留、另一窗口请求被详情草稿拒绝、成功后旧详情缓存不会带回旧计划、截止与提醒保持不变；关闭捕获再打开恢复未提交输入。
- 捕获关闭失败时保留文本且不关闭，关闭按钮与 Esc 共用入口；已有成功反馈和 720ms 自动关闭行为保留。
