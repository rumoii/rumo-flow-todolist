# Rumo-Flow v0.9.0-rc.1

预发布版本，用于试用快捷安排与今天执行交互，不替换最新正式版 v0.8.0。

## 主要变化

- 普通任务行和周卡片可直接安排今天、明天、本周、本月、未安排或指定日 / 周 / 月；周拖放共用同一安排命令。
- 今日重点独立于普通置顶。设为重点同时安排到今天，取消重点不取消执行计划。
- 今天页面依次展示重点、其他任务和折叠的待处理提醒；到期及过往任务可就地安排，搜索和标签筛选一致生效。
- 快捷安排只改变执行计划、重点及修改时间，不改变截止日期、提醒和已通知标记。窗口之间先保留输入；目标任务有未保存详情草稿时拒绝覆盖，并提供详情处理入口。
- 快速添加说明计划去向；快速捕获按实际保存结果说明清单归属，右上角新增关闭按钮，关闭前保留未提交输入。
- 包含 v0.8.0 之后的复盘问题表述及“展开完整复盘”按钮改进。批量选择重做和复盘衔接扩展不在本版范围。

## 试用与回退

1. 安装前从旧版导出备份，并完全退出应用及托盘。预览版沿用原应用标识，不是并排安装的独立应用。
2. 相对 v0.8.0 不新增数据库迁移、持久化字段或备份版本；继续使用备份 v5，不恢复旧版错误实现或新增兼容层。更早版本的升级要求仍见 [v0.8.0 说明](v0.8.0.md)。
3. 主进程、preload 与 renderer 的内部安排契约同步交付，不要混用不同版本的程序文件。需要回退时完全退出预览版，再整体安装 v0.8.0；重装程序不会自动撤销已保存的计划，需要时使用安装前备份恢复。
4. 安装、覆盖升级、卸载、个人数据回退及长期使用仍待验收，不以临时数据的打包程序测试替代这些步骤。

## 发布门禁

在最终候选提交上运行类型检查、单元 / SQLite、浏览器模拟接口、生产构建及真实 Electron 测试；生成全新 Windows x64 NSIS 安装包后，再运行打包 EXE 的完整桌面测试。全部桌面测试使用临时 userData，不接触个人数据库。

检查包内版本、app.asar 与构建文件一致性、SQLite 原生模块、图标、blockmap 结构与分块边界、签名及 SHA-256。只上传安装 EXE、配套 blockmap 和 SHA-256 文件；先创建 Draft Pre-release，回下载核对三项资产后公开，明确不设为 Latest。

开发和本地试装包证据见 [验证记录](../EVIDENCE-task-arrangement.md)。该记录不替代本预览版验证；最终提交、检查结果与资产哈希记录在 GitHub Release 正文中。

## 已知边界

- Windows 安装包未签名，SmartScreen 可能显示提示。仅从项目 Release 下载，并核对校验值。
- 系统通知点击、托盘、全局快捷键人工操作、断电恢复、长期运行及所有时区 / 夏令时组合未完整验收。
- 历史决策文档的四项外部格式校验问题仍保留记录，未为本次发布扩大修改范围。
