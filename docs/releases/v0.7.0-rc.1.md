# Rumo-Flow v0.7.0-rc.1

这是预发布版本，用于试用独立草稿与模块化改造，不替代最新正式版 v0.6.1。

## 本轮变化

- 任务详情、每日复盘、视频编辑与快捷捕获支持独立草稿，停止输入约 500 毫秒后自动保留；重新打开应用可恢复已落盘内容。
- 草稿保留不等于正式保存。任务修改、视频思考和复盘仍需手动保存，未提交复盘不计入完成统计。
- 全局新建统一进入快捷捕获窗口，不切换主窗口页面；成功保存后同步相关窗口，后台刷新不覆盖正在编辑的内容。
- 补齐任务详情的键盘打开、焦点管理与返回行为；心流切页保留未完成输入。
- 按业务域拆分前后端职责；草稿使用修订号和数据代际保护，正式保存与草稿清理同事务，备份、恢复和正常退出前等待窗口确认。
- 数据库新增迁移 8，备份格式升级到 v4，包含正式数据和草稿；继续支持导入历史备份格式。

## 升级与回退

1. 升级前使用旧版应用导出 JSON 备份，并正常退出旧版；不要直接复制运行中的 SQLite 文件。
2. 保留这份旧格式备份。旧应用不能读取 v4 备份，不承诺旧程序直接操作升级后的数据库；需要回退时使用旧版备份恢复。
3. 恢复备份会替换正式数据与草稿；恢复没有草稿的旧格式备份后，草稿为空。恢复前会自动保留当前快照。
4. “草稿已保留”才表示写入成功；强制结束或断电可能丢失尚未确认落盘的最后输入。

## 验证与已知边界

源码、浏览器模拟接口、真实 Electron/SQLite 与打包程序分层验证，详细命令与结果见 docs/EVIDENCE-stabilization.md。测试只使用临时数据目录，不操作个人数据库。

候选包已通过类型检查、77 项单元/SQLite 测试、18 项浏览器测试、2 项真实 Electron 测试和 2 项打包 EXE 测试。浏览器复验曾出现拖拽和动画时序失败，改进测试同步后保留原断言并通过最终全套；不将此前失败计为通过。

实际安装、覆盖升级、卸载、个人数据升级、系统通知点击、托盘与全局快捷键的人工操作、断电恢复和长时间运行仍待验收，因此本次作为 RC 发布。

Windows x64 安装包未签名，SmartScreen 可能显示提示。发布资产包含安装包、配套 .blockmap 与 .sha256；下载后可使用 PowerShell 的 Get-FileHash -Algorithm SHA256 核对安装包。
