# Rumo-Flow v0.9.0-rc.2

预发布版本，用于试用更新入口、批量操作与心流历史，不替换最新正式版 v0.8.0。

## 主要变化

- 设置增加“更新与关于”：版本信息、检查更新、启动检查开关及 GitHub 问题反馈。用户主动下载并确认安装，普通退出不会自动安装；安装前协调各窗口保留草稿。
- 更新失败展示简短说明，技术详情默认折叠，在独立限高区域滚动并可复制；缺少更新元数据不会误报为“已是最新版”。
- 通过“选择任务”在原任务行和周卡片中批量操作，遵循当前筛选与展开范围，最多 500 项；批量安排保留提醒与同日重点，草稿冲突整批拒绝。
- 优先级改称“重要程度”，弱化标识，与“今日重点”分工独立；修复计划选择器打开后无响应和滚动定位问题。
- 允许补录过去日期的视频与复盘，归属所选日期，不自动打开外部视频。读取空白日期不产生空记录，已有日期保留视频额度。
- 心流增加按月份分组的历史时间轴，支持日期、关键词、待补思考及已复盘筛选、分页和多日展开阅读；进入编辑后返回保留筛选、展开与滚动位置。

## 安装与更新

1. 本 RC 需从 Release 手动下载安装。检查更新仅面向正式版，不接收预发布，也不会自动降级到 v0.8.0。旧 Release 缺少更新元数据时可能显示检查失败；真实下载、安装与重启链路仍待验收。
2. 安装前导出备份，并完全退出应用及托盘。预览版沿用同一应用标识，不是并排安装版本。Windows 安装包未签名，SmartScreen 可能提示；仅从项目 Release 下载并核对 SHA-256。
3. 相对 v0.9.0-rc.1 不新增数据库结构或备份格式迁移，保持 schema 8 与备份 v5。更早版本要求见 [v0.8.0 说明](v0.8.0.md)。不要混用不同版本的程序文件。
4. 回退时完全退出应用后整体安装旧版；重装不会撤销已保存的数据，需要时使用安装前备份恢复。本轮不再次覆盖本地安装。

## 发布验证

最终候选提交须通过类型检查、单元 / SQLite、浏览器模拟接口、生产构建与源码 Electron 测试。重新生成 Windows x64 NSIS 包后，执行包内完整 Electron 测试，检查 app.asar 与构建文件、包内版本、SQLite 原生模块、图标、blockmap 分块边界和资产哈希。桌面测试使用临时 userData，不接触日常数据库。

只上传 EXE、配套 EXE.blockmap 与 EXE.sha256；先创建 Draft Pre-release，回下载核对三项资产后公开，不设为 Latest，不上传 latest.yml，也不放宽正式版 `check:release` 门禁。候选提交、最终测试结果及哈希记录在 GitHub Release 正文中。
