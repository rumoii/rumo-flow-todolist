# Rumo-Flow v0.9.0-rc.4

预发布版本，优化任务与心流编辑体验，不替换最新正式版 v0.8.0。

## 主要变化

- 任务详情按标题、安排与重要程度、清单标签、子任务、备注、重复来源组织；默认约 600px，支持展开至右侧内容区。
- 明确区分什么时候做、最晚何时完成和到期提醒。任务有效修改自动保存；恢复旧草稿时需明确应用，冲突与失败不静默覆盖。
- 心流输入和复盘继续手动保存。离开未提交内容时可保存并继续、保留草稿并继续或取消；失败留在编辑器，部分成功不重复提交。
- 列表新建、子任务和视频链接支持跨重启恢复，保留原计划、父任务及日期关联。快速捕获失焦保留草稿后隐藏，显式关闭执行离开检查。
- 优化心流问题排版、响应式日历、深浅主题、按钮、滚动及动效。修复周看板窄列、长标签清单名和弹层操作；拆分字段组件及编辑控制器，移除重复草稿缓存。

## 数据与安装

1. RC 需从 Release 手动下载安装。检查更新仅接收正式版，不推送 RC，不自动降级到 v0.8.0。
2. 升级前导出备份并从托盘完全退出。安装包未签名，SmartScreen 可能提示；请从项目 Release 下载并核对 SHA-256。
3. 本版数据库升级至 schema 10，扩展草稿种类。已有 schema 9 升级前生成 `backups/pre-editors-*.sqlite` 一致性快照；更早版本由原迁移生成 `pre-planning-*.sqlite`。事务失败回滚，不清空有效数据。
4. JSON 备份仅支持 v6。v1–v5 在替换当前数据前拒绝；旧 JSON 备份需先在原版本恢复，再升级该数据库。旧备份文件无需删除。
5. 回退必须完全退出，使用升级前 SQLite 快照并配套原版本；不能直接用旧版写入升级后的数据库，也不能向旧版导入 v6。恢复点之后的新数据不在旧快照内。

源码、模拟浏览器和包内程序验证不等于 NSIS 安装、覆盖升级、卸载或真实自动更新验收。本次不覆盖个人安装，不迁移日常数据库；长期使用、系统通知和安全软件组合仍待验收。历史决策文档的格式遗留问题不属于本次发布功能修改。
