# Rumo-Flow v0.9.0-rc.3

预发布版本，精简搜索入口并优化任务详情与操作菜单，不替换最新正式版 v0.8.0。

## 主要变化

- 侧栏“搜索”与 Ctrl+K 打开同一入口，支持全部内容和当前列表；移除独立历史搜索页面，心流保留日期、状态筛选与历史阅读。
- 任务详情采用单页排版，默认宽 600px，可展开至右侧列表区域，侧栏保持可见。展开、收起不丢失输入，属性仍需明确保存。
- 任务行和周卡片统一提供查看详情、置顶、重要程度、删除；重要程度在同一菜单内选择，删除保留确认、回收站及撤销。
- 优化浅色、深色与紧凑窗口下的层次、滚动和动效，支持减少动态效果；修复“＋ 添加”竖排及菜单被列表裁切的问题。

## 安装与回退

1. RC 需从 Release 手动下载安装；检查更新仅接收正式版，不推送 RC，也不会自动降级到 v0.8.0。
2. 沿用原应用标识与安装目录，安装前导出备份并从托盘完全退出。Windows 安装包未签名，SmartScreen 可能提示；下载后核对 SHA-256。
3. 相对 rc.2 无公共接口、数据库结构或备份格式变化，保持 schema 8 和备份 v5。更早版本要求见 [v0.8.0 说明](v0.8.0.md)。
4. 回退需完全退出后整体安装旧版，不能混用程序文件；重装不撤销已保存的数据，必要时使用安装前备份恢复。

## 发布验证

- 界面改动的源码验证：157 项单元测试、30 项浏览器测试、8 项真实 Electron 测试通过，类型检查和构建通过，详见 [验证记录](../DESIGN-workspace-polish.md)。
- 最终候选需重新检查类型及构建，生成独立 Windows x64 NSIS 包，对包内 EXE 执行完整桌面测试；校验版本、构建文件一致性、SQLite 原生模块、图标、blockmap、签名状态和 SHA-256。
- 只上传 EXE、EXE.blockmap 和 EXE.sha256。先创建 Draft Pre-release，回下载核对后公开，不设为 Latest，不上传 latest.yml，不放宽正式更新检查器。
- 最终候选提交、包内验证结果、资产哈希及本地覆盖结果记录在 GitHub Release 正文。所有自动化桌面测试使用临时 userData，不修改个人数据。
