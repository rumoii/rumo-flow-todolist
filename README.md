# rumo-Flow-todolist

简洁、专注、离线优先的桌面待办清单应用。Rumo-Flow 使用 Vue 3、TypeScript、Electron 和 SQLite 构建，帮助你把注意力放在下一件重要的事上。

[简体中文](README.md) · [English](README.en.md)

## 功能

- 总计划、今天、本周、本月、已逾期、收集箱、已完成和自定义清单视图
- 快速添加、统一搜索（全部内容 / 当前列表）、拖拽排序，以及按清单、重要程度或标签分组
- Quick Add Magic：通过 `#标签`、`!p1`、`@明天`、`~清单名` 等标记快速补充任务属性
- 截止日期与时间、提醒、未设置/低/中/高重要程度、今日重点、标签和备注
- “心流”每日复盘：视频与复盘补录、来源与思考记录、三问/六问复盘、关联行动、月历和七日趋势
- 心流历史时间轴：按日期回顾、关键词与日期范围筛选、多日原地展开、编辑后返回阅读位置
- 每天、每周、每月重复任务，并自动生成下一项
- 子任务与可展开到列表区域的任务详情抽屉
- 完成、恢复和删除任务后的限时撤销
- 任务详情、心流复盘、视频思考与快捷捕获草稿自动保留，切页和重启后可恢复
- 系统托盘、`Ctrl+Alt+Space` 全局快捷捕获和 Windows 本地通知
- 浅色/深色主题、舒适/紧凑密度和快捷键帮助
- SQLite 本地持久化，数据默认只保存在当前设备
- JSON 备份导出与恢复；恢复前自动保存当前数据，导入失败时保持现有数据不变
- Electron 桌面窗口状态记忆

## 设置与业务入口

「标签管理」独立为侧栏业务页面；视频额度在「心流 → 输入记录」调整，提醒时间在「心流 → 每日复盘」调整。「设置」仅保留外观、快捷键、数据与备份，并使用随主题变化的 Windows 标题栏。以上功能包含在 v0.8.0 中。

详见 [设置与桌面外观验证记录](docs/EVIDENCE-preferences.md)。

历史记录与交互说明见 [心流历史设计](docs/DESIGN-flow-history.md)，本地试装与验证范围见 [验证记录](docs/EVIDENCE-updates-batch.md)。

v0.9.0-rc.3 的界面精简：侧栏顶部“搜索”或 `Ctrl+K` 统一查找任务、视频和复盘，也可应用当前列表关键词筛选；心流历史保留日期与状态筛选。详情采用单页编辑并支持展开，任务菜单统一提供详情、置顶、重要程度和删除，说明见 [搜索与详情交互](docs/DESIGN-workspace-polish.md)。

## 开发

环境要求：Node.js 22+、pnpm 9+。

```bash
pnpm install
pnpm dev
```

常用检查：

```bash
pnpm typecheck       # TypeScript 类型检查
pnpm test            # 单元与 SQLite 集成测试
pnpm test:e2e        # Playwright 浏览器测试
pnpm test:desktop    # 构建后使用临时用户目录验证真实 Electron 与 SQLite
pnpm build           # 生产构建
pnpm package         # 构建 Windows 安装包
```

## 数据与备份

应用数据保存在 Electron 的用户数据目录中，数据库文件名为 `rumo-daiban.sqlite`。推荐使用应用内“设置 → 数据与备份”导出 JSON 备份，不要直接复制正在运行中的 SQLite 文件。恢复备份前会自动生成 `backups/pre-import-*.json`，用于在导入前保留当前快照。

当前源码仅导出和导入 `rumo-flow-backup` v5，包含正式数据、执行计划、回收站、行动来源和未完成草稿。v1–v4 备份明确拒绝，不会清空当前数据。导入前自动保存当前 v5 快照。

草稿在停止输入约 500 毫秒后自动保留，界面显示“草稿已保留”才表示已经落盘。正式任务修改、视频思考和复盘仍需手动保存；草稿不计入已完成复盘。正常切页、关闭窗口和退出会等待草稿写入，失败时可以重试或明确放弃。强制结束或断电无法保证最后尚未落盘的输入。

数据库迁移 9 在升级已有数据库前，将一致性 SQLite 快照保存到数据库目录下的 `backups/pre-planning-*.sqlite`。旧任务保持编号、截止日期和草稿，执行计划初始为未安排；任务草稿升级为 v2。回退需关闭所有应用进程并恢复升级前快照，不能用旧应用打开升级后的数据库或导入 v5。

### 计划与心流行动

- 执行计划和截止日期独立：任务只有一个日、周或月计划，可逐步细化；周一为周起点，月份采用自然月。
- 今天区分今日重点、其他日计划，以及折叠的今日到期和过往未完成提示。未完成任务不会自动滚动到今天。
- 快速输入的 `@今天`、`@明天`、`@YYYY-MM-DD` 仍然只设置截止日期。计划页创建采用当前页面的计划精度，全局捕获保持未安排。
- 复盘默认三问，可展开六问，共用一份草稿。保存复盘或视频正文后，可以创建多个关联行动；复盘行动默认明天，视频行动默认未安排。
- 历史搜索覆盖已保存的任务、视频和复盘，不搜索草稿或回收站。来源删除后保留任务及最小来源信息。
- 批量操作支持完成、移动、添加标签、调整计划和截止日期、移入回收站。回收站保留 30 天，恢复父任务仅恢复同次删除的子任务。

## 项目结构

```text
electron/              Electron 主进程、IPC、窗口状态和 SQLite 数据层
electron/database/     按任务、组织、心流、设置、草稿拆分；备份服务统一处理事务
electron/ipc/          按业务域注册 IPC，统一处理写入后通知
src/                   Vue 渲染进程、页面和共享类型
src/features/          任务工作区、详情、排序、偏好与心流状态
src/composables/        草稿协调与共享界面逻辑
tests/                 Vitest 与 Playwright 测试
electron.vite.config.ts
package.json
```

桌面测试只使用任务创建的临时 `userData`，不会访问个人数据库。浏览器测试注入内存接口，不能替代真实桌面测试。安装包安装、卸载、系统通知点击和个人数据升级应另行验收。

浏览器测试默认使用独立的 5173 端口，不复用已有服务；占用时可设置 `RUMO_E2E_PORT`，例如 PowerShell 中执行 `$env:RUMO_E2E_PORT='5186'`。功能验证见 [快捷安排验证记录](docs/EVIDENCE-task-arrangement.md) 和 [计划与行动验证记录](docs/EVIDENCE-planning.md)，当前发布门禁和未验收边界见 [预览版说明](docs/releases/v0.9.0-rc.3.md)。

### 更新与批量操作

“设置 → 更新与关于”提供版本信息、可关闭的启动检查、正式版手动下载与确认安装、GitHub 问题反馈。关闭设置不停止下载，普通退出不自动安装；首次获得更新能力仍需手动安装新版。检查更新仅面向正式版，不推送 RC；本预览版需从 Release 手动下载安装。

任务页通过“选择任务”在原任务行和周卡片选择，底栏处理当前筛选、已展开分区中的任务，最多 500 项。批量安排不会改变截止提醒，有未保存详情修改时整批拒绝。

验证结果见 [更新与批量操作](docs/EVIDENCE-updates-batch.md)，正式更新资产与隔离安装验收见 [更新发布说明](docs/UPDATE-RELEASE.md)。发布前运行 `pnpm check:release <本次正式版本输出目录>`，仅构建不会自动发布。
